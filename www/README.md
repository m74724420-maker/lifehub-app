# Мой Личный Хаб

Личное PWA-приложение для телефона: задачи, заметки, дневник, привычки, бюджет, здоровье (шагомер, вода, сон).

## Запуск
```powershell
cd "C:\Users\Мария\Documents\Проект по умолчанию\lifehub"
python -m http.server 3000
```
- На ПК: http://localhost:3000
- На телефоне (та же Wi-Fi): http://<IP-вашего-ПК>:3000

## Установка на телефон
Откройте сайт в браузере телефона → меню → «Добавить на главный экран». Приложение работает офлайн.

## Функции
- Задачи с приоритетами и дедлайнами
- Заметки с цветами и поиском
- Дневник с настроением (редактирование/удаление)
- Привычки со streak
- Бюджет: расходы/доходы, фильтр по месяцу
- Здоровье: шагомер (акселерометр), вода с целью, сон, шаги вручную
- Настройки: имя, пароль, цель воды, экспорт/импорт JSON, статистика
- PWA, офлайн

## Данные
Хранятся в браузере (localStorage). Экспорт/импорт через Настройки.

## Выкладка

### Netlify Drop (самый простой)
1. Откройте https://app.netlify.com/drop
2. Перетащите папку `lifehub` на страницу
3. Получите ссылку вида https://xxx.netlify.app — откройте на телефоне

### GitHub Pages
1. Создайте репозиторий на GitHub и загрузите содержимое папки `lifehub`
2. В репозитории: Settings → Pages → Source: Deploy from a branch → Branch: main → / (root)
3. Сайт будет доступен по https://<username>.github.io/<repo>/

### Vercel
1. Установите Vercel CLI: `npm i -g vercel`
2. В папке `lifehub`: `vercel` → следуйте инструкциям

## Шагомер
Использует датчик движения (DeviceMotion). На iOS требуется разрешение — нажмите «Старт» и дайте доступ. На ПК без датчика не работает (используйте ручной ввод).
